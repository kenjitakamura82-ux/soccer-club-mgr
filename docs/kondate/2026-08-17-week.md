# 今週の献立（2026/8/17 月 〜 8/23 日）

8/15（土）の買い出しレシートにあった食材を使い切る前提で組んだ 1 週間の夕食プランです。
生鮮（豚ロース・豚こま・合挽肉・葉物系）を前半に、冷凍・常温ストックを後半に配置しています。

## 買ってある主な食材

| 分類 | 品目 |
| --- | --- |
| 野菜 | ミニトマト / かぼちゃ / 人参 / じゃがいも / 玉ねぎ |
| 肉 | 豚ロース切り身 / 豚こま切れ / 牛豚合挽肉 × 2 パック |
| 冷凍 | 餃子（bibigo）/ 冷凍唐揚げ / ミックスベジタブル / おうちドリア |
| 卵・乳 | 卵 / 牛乳 / バター / ヨーグルト各種 |
| 調味料 | マヨネーズ / ケチャップ / イタリアンドレッシング / ごま / 片栗粉 |
| 主食・その他 | 米（秋田県産）/ 納豆 / チーズ蒸しパン / アイス |

> 合挽肉は 2 パックあるので、**1 パックは買った日のうちに冷凍**しておき、木曜に冷蔵解凍して使います。

## 1 週間のメニュー

### 月 8/17 — ポークチャップ
- 主菜: 豚ロースのポークチャップ（玉ねぎ・ケチャップ・バター）
- 副菜: 粉ふきいも / ミニトマト
- 汁物: 玉ねぎとわかめの味噌汁
- ごはん
- ひとこと: 豚ロースは片栗粉を薄くまぶして焼くと、ソースがよく絡んで柔らかく仕上がります。

### 火 8/18 — 手ごねハンバーグ
- 主菜: ハンバーグ（合挽肉①・玉ねぎ・卵、つなぎは片栗粉）／ケチャップソース
- 副菜: 人参のグラッセ / ミックスベジタブルのバターソテー
- 汁物: コンソメスープ
- ごはん
- ひとこと: タネを多めに作って 2 〜 3 個分を成形して冷凍しておくと、翌週の弁当に回せます。

### 水 8/19 — 餃子＋豚こまの中華炒め
- 主菜: 冷凍餃子（bibigo）
- 副菜: 豚こまと人参・玉ねぎの中華炒め（片栗粉でとろみ、仕上げにごま）
- 汁物: 卵スープ
- ごはん
- ひとこと: 豚こまは購入から 4 日目なので、この日までに使い切ります。

### 木 8/20 — かぼちゃのそぼろ煮
- 主菜: かぼちゃと合挽肉②のそぼろ煮
- 副菜: 納豆 / だし巻き卵
- 汁物: じゃがいもの味噌汁
- ごはん
- ひとこと: 前日夜に冷凍の合挽肉を冷蔵庫へ移して解凍しておきます。

### 金 8/21 — ドリアの日
- 主菜: おうちドリア（冷凍）
- 副菜: ミニトマトとレタスのイタリアンドレッシングサラダ
- 汁物: かぼちゃのポタージュ（残ったかぼちゃ＋牛乳＋バター）
- ひとこと: 平日の終わりは加熱するだけの日。かぼちゃの残りをここで使い切ります。

### 土 8/22 — 唐揚げとポテトサラダ
- 主菜: 冷凍唐揚げ
- 副菜: ポテトサラダ（じゃがいも・人参・卵・マヨネーズ）/ ミニトマト
- 汁物: コーンスープ
- ごはん
- ひとこと: 試合や練習で帰宅が遅くなっても対応しやすい構成。ポテトサラダは午前中に作り置き。

### 日 8/23 — 他人丼
- 主菜: 豚こま（または残りの肉）と玉ねぎの卵とじ丼
- 副菜: 冷奴 or 納豆 / ミニトマト
- 汁物: 人参とじゃがいもの味噌汁
- ひとこと: 冷蔵庫の残り野菜を全部入れて、週の終わりにリセットします。

## 買い足しメモ（週の途中で必要になりそうなもの）

- レタスなどの葉物（金曜のサラダ用）
- 豆腐・油揚げ（味噌汁・冷奴用）
- 牛乳（ポタージュで使うため、朝食分が足りなければ）
